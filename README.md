# 企业微信套件

企业微信文档、消息、日程、会议、待办与通讯录操作。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/wecom-unified#v1.0.5 --skill wecom-unified
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill wecom-unified
```

## 内容

技能正文在 `skills/wecom-unified/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/wecom-unified/payload/`，不要反向同步。版本以 git tag 为准。
